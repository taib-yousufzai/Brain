# Skill: Impeccable (Zero-Flaw Pixel Polish & Verification)

**Domain**: Design & UI Quality Assurance  
**Rating**: 10.0 / 10  
**Target**: Zero-Flaw Visual Quality, Layout Alignment & Production Verification

---

## 👁️ Core Principles of Impeccable Quality

### 1. Pixel-Perfect Alignment
- All containers, inputs, buttons, and badges must strictly adhere to grid baseline boundaries.
- No loose pixels, unexpected margin collapses, or overflowing text lines.

### 2. High-Contrast Legibility & Accessibility
- Ensure contrast ratio between text colors and surface backgrounds exceeds WCAG AAA standards.
- Use explicit font weights (`font-medium`, `font-bold`) and monospace indicators for key metrics.

### 3. Interactive State Completeness
- Every interactive element (button, tab, select, link) must specify hover, active, focus-visible, and disabled states.
- Hover feedback must be responsive and immediate (`cursor-pointer`, subtle background shifts).

### 4. Zero Unhandled Errors or Broken Fallbacks
- Provide graceful empty state displays when arrays or filter queries return zero results.
- Implement robust skeleton loaders for asynchronous or loading states.
